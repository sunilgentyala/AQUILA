Architecture

Three layers, one boundary that scales

The interface layer talks to backends purely through Qiskit's EstimatorV2/SamplerV2 primitive protocol. Nothing above that boundary refers to the simulator directly — a hardware-backed primitive implementation would satisfy the interface without changing the optimizer or agent code.

Security layer

Pairwise post-quantum-secured channel: ML-KEM-768 encapsulation + AES-256-GCM + ML-DSA-65 signature, verify-then-decrypt ordering. Verified against wrong-recipient, tampering, and impersonation attacks.

Interface layer

TaskAllocationProblem → Ising Hamiltonian, dispatched to any backend exposing estimator()/sampler(). Aer simulator today; real QPU later, no API change.

Optimizer layer

Multi-restart QAOA (COBYLA outer loop) with full-distribution post-selection, benchmarked against greedy (LPT) and multi-restart simulated-annealing baselines.

Backend (pluggable)

Aer statevector simulator, with an optional depolarizing noise model for studying solution-quality degradation under simulated NISQ-era hardware.

Evaluation

Real results, honestly reported

Every number below comes from the evaluation harness in evaluation/ — reproducible, with results and figures checked into the repo.

Solution quality. Exact-optimum success rate with Wilson 95% intervals, 30 instances per point, equal sample budgets (3 × 1,024). QAOA is statistically indistinguishable from uniform random sampling and from the same circuit with random parameters (paired exact tests, all p ≥ 0.58). Tuned simulated annealing, Karmarkar-Karp and greedy LPT fall behind on real-valued weights.
Runtime. Exact enumeration and subset-sum dynamic programming solve every tested size in well under 0.1 s, two to four orders of magnitude faster than QAOA on the simulator. Simulation time says nothing about how a QPU-backed deployment would scale.
Security overhead. The PQC envelope seals in about 0.5 ms and opens in about 0.17 ms, between P-256 and RSA-3072 on the open side, but a 512-byte payload becomes 5,007 bytes on the wire against roughly 1.2–1.3 KB for classical baselines, mostly the 3,309-byte signature. P-256 is the fastest option per message.
Noise study. The Hamiltonian expectation ratio collapses toward 0 as depolarizing error rises to 5%. Optimal-probability enrichment over uniform stays near 1 at every noise level, including none, so best-of-samples success reflects sampling, not circuit quality. At small shot budgets under noise, QAOA is modestly ahead of uniform sampling on 8 instances per size; this is suggestive, not conclusive.

Get started

Install and run

Install
pip install -e ".[dev]"
Run the end-to-end demo
python examples/demo_end_to_end.py
# requester agent -> QAOA solve -> PQC-secured response, full cycle

python evaluation/quality_controls.py  # reproduce the controlled quality sweep
python evaluation/analyze.py           # regenerate figures
